🚀 Excited to share my latest project — Codexia, an AI-powered cloud code editor & workspace!

Codexia is a full-stack, cloud-native IDE designed to streamline developer workflows by bringing intelligent AI assistance, file management, live previewing, and interactive terminals directly into the browser.

Think of it as your personal cloud IDE with an autonomous AI coding agent built right in.

✨ Key Features & Capabilities:
• 🤖 Autonomous AI Coding Agent: Powered by Google Gemini & LangGraph to create files, update project trees, debug code, and stream responses in real-time via Server-Sent Events (SSE).
• 📂 Project & File Management: Full CRUD operations for files, folders, and multi-file projects with instant hierarchy updates.
• ⚡ Live In-Browser Preview: Real-time preview environment for HTML/CSS/JS and React applications.
• 💻 Cloud Terminal: Built-in interactive terminal sessions connected via real-time WebSocket communication.
• 💳 Credit-Based Tier System: Seamless checkout and plan upgrades integrated with Cashfree Payments PG SDK.
• 🔐 Secure Authentication: Google OAuth authentication via Firebase Admin SDK with secure, distributed Redis sessions.

🏗️ Architecture & Tech Stack:
• Frontend: React 18, Vite, Redux Toolkit, TailwindCSS, Lucide Icons, Framer Motion — deployed with AWS S3 + CloudFront CDN.
• Backend Microservices: Node.js & Express distributed microservices architecture consisting of:
  - API Gateway (Reverse proxy, route matching, auth validation, SSE & WebSocket proxying)
  - Auth Service (Firebase Admin SDK & Redis session management)
  - AI Service (LangGraph agent, tools, SSE streaming, Gemini model)
  - Project Service (CRUD operations, caching with Redis)
  - File Service (Filesystem manipulation & storage)
  - Terminal Service (WebSocket node-pty interactive terminal)
  - Payment Service (Cashfree Payments PG integration & credit allocation)
• Database & Cache: MongoDB Atlas (distributed database) + Redis / AWS ElastiCache (high-performance caching & session store).
• Cloud & DevOps: Dockerized microservices, AWS ECS Fargate, Application Load Balancers, CloudFront CDN, and S3.

💡 Engineering Highlights & Learnings:
• Architected a robust API Gateway with reverse proxying for both HTTP/SSE and bidirectional WebSocket streaming.
• Integrated Cashfree Payments PG v3 SDK for frictionless, modal-based checkout experiences.
• Designed distributed Redis caching and session management to ensure zero-downtime, stateless horizontal scaling.
• Mastered cross-domain cookie security (SameSite, Secure flags) across CloudFront CDN distributions and custom microservice endpoints.
